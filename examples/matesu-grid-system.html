About

Design that earns
its position.

Matesu is an independent designer and producer working between music, photography, and code — from the Vale do Paraíba, interior de São Paulo. Every project begins with the same question: what needs to be said?

We build visual systems — not logos, not websites, not campaigns — but the underlying structures that make communication consistent, scalable, and unmistakable. The grid is our method, not our style.

  • Active since 2015 — Vale do Paraíba, SP
  • Producing with @blackmesaent and bloodworm trax
  • Sound, image, and code as one practice
  • Published at www.matesu.me
