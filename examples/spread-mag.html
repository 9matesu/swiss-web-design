Essay

The grid
is not
the cage

Müller-Brockmann called the grid a system of order that makes the message more easily understood. The order is what creates the freedom. Once a layout sits on a shared structure, you can break it deliberately for emphasis — a full-bleed image, an oversized numeral, a column that refuses to align — and the break reads as intentional rather than accidental, because the eye has a baseline to measure it against.

On the web the constraint is variable. Screen widths shift, fonts load late or not at all, users zoom, translate, override. A rigid pixel grid fails here. A proportional grid — columns as fractions, gaps as ratios, type sizes in steps — survives the variance. The Swiss method was always proportional: the modular grid, the baseline grid, the type scale. These translate to CSS custom properties without loss.

The trap is mistaking the grid for the design. The grid is the instrument; the composition is the music. A page where every element snaps to the module without tension is a score played without dynamics. The Swiss masters knew this: Hofmann's posters breathe because the grid is felt, not seen. The white space is shaped as deliberately as the black marks.

Order is not imposed from outside; it grows from the material itself. — Emil Ruder, Typographie (1967)
